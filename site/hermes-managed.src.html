    08Cutting the bill

    A cache miss costs 2–50× a hit

    Fresh input is about half of every Claude and OpenAI bill, where cache writes cost 12.5× a read. Anything that keeps the prompt prefix stable shows up directly on the invoice.

    Claude Sonnet 5 · Typical month · by cache hit rate
    1. Keep the prefix stable. Don’t change tools, skills or rules mid-session. Hermes freezes MEMORY.md at session start for exactly this reason.
    2. Route memory extraction to a cheap model. On Sonnet 5, extraction costs $29 a month on the main model versus $3 on GPT-5.6 Luna.
    3. Load skills only when a task needs them. Compile calls ran at ~32K tokens versus ~18.5K for questions: skill instructions plus the notes read.
    4. Batch what nobody waits for. Nightly compiles can use batch APIs at 50% off (OpenAI, Anthropic, Gemini, Qwen).

    13Caveats

    Before you switch

    Your notes leave the machine

    Every prompt carries the excerpts the agent read. Prefer no-training defaults and check retention: Bedrock stores nothing; Azure abuse monitoring keeps up to ~30 days; Claude Fable 5.1 requires 30-day retention.

    Prices move

    GPT-5.6 Sol is on a promo to at least 21 Nov 2026. Gemini 3.8 Flash doubles on 1 Jan 2027. Z.ai’s free cache storage and Qwen 3.7 Plus’s discount are labelled limited-time.

    Plan terms differ

    Anthropic restricts consumer-plan credentials in third-party tools. OpenAI tolerates ChatGPT sign-in without a formal term. GitHub officially supports only OpenCode. MiniMax, Kimi and Ollama name Hermes explicitly.

    Hosts aren’t all equal

    Nous Hermes Cloud is the only first-party host. “AI included” tiers don’t publish usage caps, and unaffiliated hosts may lag Hermes releases.

    This is a model, not a quote

    Task mix, 85% cache hits and the size of memory extraction are assumptions. Hermes logs tokens and an estimated cost per session, so compare your first week with these numbers.

    Managed tools re-open the web

    Turning on the Tool Gateway or a search API brings back the leak path the workshop closed. Keep the write sandbox, AGENTS.md and citation checks.
