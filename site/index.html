Key ideas

What the rest of the day depends on

The most common setup mistake comes first: treating a memory provider as vault search.

Memory is not search

Memory provider (Hindsight, Mem0, Honcho…)Vault search (QMD)
InputYour conversations with the agentYour notes
Answers“What do I prefer? What did we decide last week?”“What do my notes say about X?”
Written byThe agent, automatically after each turnYou. The index mirrors your files
Don’tBulk-load your vault into itExpect it to remember chats

Two authors, two zones

“If the agent writes everything, the wiki drifts toward generic prose. If I maintain everything manually, it decays.”Danny Shmueli, on his Hermes + Obsidian workspace

Everything outside _hermes/ is yours: decisions, taste, voice. The agent reads it and never edits it. Inside _hermes/wiki/ the agent maintains summaries, entity pages and cross-links, and you review them.

Compile, don’t re-retrieve

RAG rediscovers knowledge on every question. Karpathy’s LLM Wiki pattern compiles it once into linked Markdown that improves over time. Hermes ships it as the bundled llm-wiki skill:

  • Ingest: read sources, create or update pages (2+ mentions, or central to one source), update index.md, append to log.md
  • Query: read the index, read pages, answer with citations, optionally file the answer
  • Lint: orphans, broken links, stale pages, contradictions

For an existing vault the vault is the raw layer: pages cite sources: ["[[Note Name]]"] instead of copying notes into raw/.

Hybrid search, sized to the vault

NotesWhat’s enough
< 50grep
50–500Full-text keyword search (BM25)
500–5,000+ vectors, fused by rank
5,000++ reranking and credential filtering

Keywords win on error codes and ticket IDs; vectors win when a note uses different words than your question. A short description per folder (qmd context) helps the reranker as much as the algorithm does.

Local models: the fine print

  • Hermes refuses tool use below 64K context. Original Qwen3 models stop at 40,960 in Ollama.
  • An 8B model found the right note, skipped reading it, and invented the answer.
  • A mixture-of-experts model (30B total, 3B active) stays usable on a 10 GB GPU even when half of it sits in system RAM.
  • Hermes and Hindsight must request the same num_ctx, or Ollama reloads the model on every switch.
  • Local models overclaim. “Done” and “verified” are not evidence.

A ladder of safety

  • AGENTS.md: “outside _hermes/ is read-only”soft
  • Git auto-commit: an undo button, not a guardrecovery
  • Disable web, browser, TTS, image and vision tools (on by default)hard
  • HERMES_WRITE_SAFE_ROOT blocks file-tool writes; shell redirects aren’t coveredfile tools
  • Deterministic checks after every agent changedetects
  • Hermes in Docker, vault mounted read-onlyhard

Memory needs hygiene

Auto-retain stores whatever happened. On the reference run that included a hallucinated answer with made-up entities, two false “all fixed” claims, and a one-off test permission that could have become standing consent.

Review the Hindsight UI after a bad session, delete that session’s memories by ID, and write a retain mission that says what not to keep.

Install

From empty machine to a verified answer

Commands assume Linux with a user-level setup (no sudo needed). macOS and Windows differ only where noted. Replace $VAULT with the absolute path to your vault.

  1. Scan your vault for secrets

    Your notes are about to be indexed and read by an agent. Real vaults contain pasted tokens; know where yours are before anything else touches them.

    export VAULT="$HOME/Obsidian/MyVault"
grep -rlIE --include='*.md' \
  '(sk-[A-Za-z0-9_-]{20,}|AKIA[0-9A-Z]{16}|ghp_[A-Za-z0-9]{30,}|github_pat_[A-Za-z0-9_]{30,}|xox[baprs]-[A-Za-z0-9-]{10,}|-----BEGIN [A-Z ]*PRIVATE KEY|eyJ[A-Za-z0-9_-]{20,}\.[A-Za-z0-9_-]{20,}|AIza[0-9A-Za-z_-]{35}|mongodb(\+srv)?://[^ ]*:[^ ]*@)' \
  "$VAULT"

    Rotate anything real, then remove it from the note. Git history keeps the old copy.

    Hermes loads AGENTS.md from the folder it starts in. Put the rules at your vault root:

    $VAULT/AGENTS.md (minimum version)
    # AGENTS.md — rules for AI agents working in this vault
## Ownership
1. Everything outside `_hermes/` is human-written and READ-ONLY. Don't edit, move, rename or delete it unless
   the user explicitly asks in this conversation.
2. `_hermes/` is agent-owned. The LLM Wiki lives in `_hermes/wiki/`; follow its SCHEMA.md.
## How to find things
1. Search first with the `qmd` MCP tools: `query` (lex: for exact terms, vec: for questions), then `get` to READ the notes.
2. `search_files` only for exact regex or very recent edits.
## Answering
- Cite sources as [[Note Name]] wikilinks (no path, no .md). Say when the vault has nothing.
## Secrets
- Never copy credentials into answers, wiki pages, memory or logs. Write [REDACTED credential — see [[Note]]].
## Don'ts
- No git commands. Don't touch .obsidian/. Ask before changing more than 10 wiki pages.

    Create _hermes/wiki/SCHEMA.md, index.md and log.md (or ask Hermes to initialise the wiki). The one change for an existing vault goes in the schema:

    ## Sources — adaptation for an existing vault
This wiki does not use raw/. The vault itself is the immutable source layer.
Sources are vault notes referenced by wikilink: sources: ["[[Note Name]]"]. Never copy or modify them.
Wikilinks between wiki pages use the file name: [[unified-memory]], not the page title.
After any change, run _hermes/scripts/wiki_check.py and fix until it exits 0.
    $VAULT/_hermes/scripts/wiki_check.py
    #!/usr/bin/env python3
"""Deterministic LLM-Wiki check (don't let the model grade its own homework).

Checks every wiki page (except SCHEMA.md / log.md) for:
  - dangling [[wikilinks]] (Obsidian resolves by vault path or by basename)
  - tags outside the SCHEMA.md "## Tag Taxonomy" section
  - frontmatter: present, keys unindented, required keys present
  - sources: every entry is a [[wikilink]] that resolves
  - self-links, and fewer than 2 outbound links to other notes/pages
Exit code 1 if anything is found.

Usage: python3 wiki_check.py <vault> [wiki_subdir=_hermes/wiki]
"""
import re, sys, pathlib

vault = pathlib.Path(sys.argv[1]).expanduser()
wiki = vault / (sys.argv[2] if len(sys.argv) > 2 else "_hermes/wiki")
notes = {p.relative_to(vault).with_suffix("").as_posix().lower() for p in vault.rglob("*.md")}
notes |= {n.rsplit("/", 1)[-1] for n in notes}
schema = (wiki / "SCHEMA.md").read_text()
taxonomy = set(re.findall(r"`([a-z0-9-]+)`", schema.split("## Tag Taxonomy")[1].split("\n## ")[0]))
REQUIRED = ("title", "created", "updated", "type", "tags", "sources")
LINK = re.compile(r"\[\[([^\[\]|#^]+)")           # [^\[\]] skips the extra bracket of ^[[[...]]] markers

problems = total = dangling = 0
def report(kind, page, msg):
    global problems
    problems += 1
    print(f"{kind:<9} {page.relative_to(wiki)} -> {msg}")

for page in sorted(wiki.rglob("*.md")):
    if page.name in ("SCHEMA.md", "log.md"):
        continue
    text = page.read_text()
    is_index = page.name == "index.md"
    fm = re.match(r"---\n(.*?)\n---\n", text, re.S)
    if not is_index:
        if not fm:
            report("FRONTMTR", page, "missing YAML frontmatter")
        else:
            lines = [l for l in fm.group(1).splitlines() if l.strip()]
            if any(l[0].isspace() for l in lines if re.match(r"\s*[a-z_]+:", l)):
                report("FRONTMTR", page, "indented keys (Obsidian won't parse properties)")
            keys = {l.split(":", 1)[0].strip() for l in lines if ":" in l}
            missing = [k for k in REQUIRED if k not in keys]
            if missing:
                report("FRONTMTR", page, f"missing keys {missing}")
            src = re.search(r"^\s*sources:\s*\[(.*)\]\s*$", fm.group(1), re.M)
            for entry in (re.findall(r'"([^"]*)"', src.group(1)) if src else []):
                m = LINK.search(entry)
                if not m:
                    report("SOURCES", page, f"not a wikilink: {entry}")
                elif m.group(1).strip().removesuffix(".md").lower() not in notes:
                    report("SOURCES", page, f"source note not found: {entry}")
        tags = re.search(r"^\s*tags:\s*\[([^\]]*)\]", text, re.M)
        bad = [t.strip() for t in (tags.group(1).split(",") if tags else []) if t.strip() and t.strip() not in taxonomy]
        if bad:
            report("TAGS", page, f"not in taxonomy: {bad}")
    outbound = set()
    for target in LINK.findall(text):
        key = target.strip().removesuffix(".md").lower()
        total += 1
        if key not in notes:
            dangling += 1
            report("DANGLING", page, f"[[{target}]]")
        elif key.rsplit("/", 1)[-1] == page.stem.lower():
            report("SELFLINK", page, f"[[{target}]]")
        else:
            outbound.add(key)
    if not is_index and len(outbound) < 2:
        report("LINKS", page, f"only {len(outbound)} outbound link(s) to other notes (schema: >= 2)")

print(f"\n{total} wikilinks, {total - dangling} resolve, {dangling} dangling; {problems} problem(s); taxonomy has {len(taxonomy)} tags")
sys.exit(1 if problems else 0)

3bScript finds, agent fixes, script re-checks

15 min

Don’t ask the agent to lint its own wiki. Feed it the checker’s output and loop until the exit code is 0.

Troubleshooting

Every problem we actually hit

Each one is a symptom from the reference build, with its cause and the fix that worked.

21 entries
Model

“Ollama runtime context is too small for Hermes tool use”

Cause
Hermes needs at least 64,000 tokens. Original Qwen3 models are capped at 40,960 in Ollama.
Fix
Use a long-context model (Qwen3 30B-A3B Instruct 2507) and set model.ollama_num_ctx: 65536.
Model

The agent answers without reading the note

Cause
Small models call search, skip get, and fill in from training data.
Fix
A stronger model, an AGENTS.md rule to search then read, and “read the note” in the prompt. Always check one citation.
Model

The model reloads and every turn is slow

Cause
Hermes and Hindsight request different context sizes, so Ollama unloads and reloads.
Fix
Use the same value in model.ollama_num_ctx and HINDSIGHT_API_LLM_OLLAMA_NUM_CTX; set OLLAMA_MAX_LOADED_MODELS=1.
Model

VRAM is tight

Cause
QMD’s models (~2 GB) and the LLM share the GPU.
Fix
Turn on flash attention and the q8_0 KV cache, or run QMD on CPU with QMD_LLAMA_GPU=false.
Model

ollama pull gpt-oss:20b fails with “Error: EOF”

Cause
Unresolved: the registry answered, other models pulled fine.
Fix
Retry later or use a different model tag.
Tools

The agent searches the web and cites notes that don’t exist

Cause
Tool Search (on by default) hid the QMD tools; the web toolset (also on by default) became the fallback.
Fix
hermes config set tools.tool_search.enabled off and hermes tools disable web browser image_gen tts vision computer_use connections.
Tools

The agent’s own lint says everything is fine

Cause
A read loop exhausted the iteration budget, and the model wrote an all-clear anyway.
Fix
Run wiki_check.py and give its output to the agent to fix. Treat any report ending in “Iteration budget reached” as unreliable.
Tools

A fix round passes the checker but breaks citations

Cause
A checker only guards what it checks. The first version didn’t validate sources:.
Fix
Check sources, frontmatter, self-links and outbound links; review with git log -p -- _hermes/wiki.
Tools

Plugin install: “BLOCKED — community source + caution verdict”

Cause
Hermes scans plugins on install; many findings are heuristic.
Fix
Read the findings and the code before using --force.
CLI

Cause
It opens an interactive tool picker and waits for input.
Fix
Add the mcp_servers: block to ~/.hermes/config.yaml, then hermes mcp test qmd.

Cause
The pattern also matches the command line of the shell running it.
Fix
Use pgrep -af and kill by PID; wait on a marker in an output file instead.

The model promised and made zero tool calls.
Fix
Check ~/.hermes/memories/ or the Hindsight UI instead of trusting the sentence.

Hindsight memories never show up in one-shot runs

Cause
recall_sync is false by default, so recall is injected on the next turn.
Fix
Set "recall_sync": true in ~/.hermes/hindsight/config.json; look for “recalled N memories”.

Wrong facts keep coming back

Cause
Auto-retain stored a hallucinated answer or a false success claim.
Fix
Delete that session: curl -X DELETE http://127.0.0.1:8888/v1/default/banks/<bank>/documents/<session_id>, and clear bad lines from MEMORY.md.

Docker Desktop and Docker Engine resolve host.docker.internal differently.

Desktop: Ollama on 127.0.0.1. Engine: Ollama on 172.17.0.1. Test from inside the container.

Memory API reachable from the network
